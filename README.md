# Data Analyst Projects

รวมโปรเจกต์ฝึกทำจริงสำหรับคอร์ส Data Analyst แต่ละโฟลเดอร์คือ 1 โปรเจกต์ ครบทั้งไฟล์ข้อมูล คำสั่งสอน และไฟล์ประกอบ

## Projects

### project1: Data Cleaning

ล้างข้อมูลจริงในโน้ตบุ๊ก (Jupyter/Colab) แล้ว push ขึ้น GitHub, ใช้ข้อมูล Pima Indians Diabetes (สายสุขภาพ)

| ไฟล์ | คือ |
|---|---|
| `instruction.md` | ขั้นตอนล้างข้อมูล 6 ขั้นแบบละเอียด พร้อมโค้ดตัวอย่างและคำอธิบายทีละบรรทัด |
| `hint.md` | แนวคิดช่วยตัดสินใจว่าจุดไหนควรตัด/เติม/แปลงข้อมูล |
| `diabetes.csv` | ข้อมูลดิบ (768 แถว, 9 คอลัมน์) |
| `project1-lecture.pdf` | สไลด์ประกอบการสอน |

เริ่มจากอ่าน `instruction.md` ก่อน ใช้ `hint.md` ตอนติดขั้นตอนตัดสินใจ
